# 논문 작성 방향 — 지금까지의 결과를 어떻게 쓸 것인가 (2026-10-27)

**대상 독자:** 공저자. 지금까지의 실험이 무엇을 보여 주는지, 그리고 그것을 CVPR 2027 논문(11/10 초록 등록, 11/16 제출)에서 어떤 주장과 어떤 표·그림으로 쓸지를 정한다.

**관련 문서**
- 진단 중심 개요(이 문서의 바탕): [`PAPER_OUTLINE_v2_diagnosis.md`](PAPER_OUTLINE_v2_diagnosis.md)
- 교수님 피드백(일반화·ablation·SOTA) 점검: [`FEEDBACK_CHECK_2026-10-27.md`](FEEDBACK_CHECK_2026-10-27.md)
- 최종 모델 구조와 작동 원리: [`MODEL_ARCHITECTURE.md`](MODEL_ARCHITECTURE.md)
- 수치 원본: `runs/`(10-16 이후 결정적 코드), `results/LEADERBOARD.html`

모든 수치는 YOLO 계열 6 seed, OWLv2 3 seed이고, Δ는 BRECQ 대비 같은 seed끼리의 짝 차이 평균(± 95% CI)이다. LVIS AP는 점(×100), flip은 낮을수록 좋다.

---

## 1. 한 문단 결론

저비트 PTQ는 open-vocabulary 검출기에서 **calibration 어휘(COCO)의 AP보다 보지 않은 어휘(LVIS)의 판정을 먼저 무너뜨린다.** 손상이 어디에 몰리는지는 구조마다 다르고, calibration 쪽 데이터만 쓰는 누수 없는 층 단위 진단이 그것을 미리 보여 준다. 진단 결과에 따라 **게이트 교환(G), 보호(P), 공유 제약 이전(M)** 중 무엇이 들을지가 정해지고, 이 규칙을 그대로 적용하면 구조가 다른 6개 검출기 모두에서 W4 판정 충실도가 BRECQ보다 좋아진다(W4A5 LVIS AP +2.2 ~ +5.6점).

| # | 주장 | 근거 | 강도 |

| R9 | calibration 어휘로 학습하면 held-out이 나빠진다 | PromptCal W4A8 −1.06 | 보조(음성 결과) |

## 3. 논문의 중심을 어디에 둘 것인가

**방법(GPM)이 아니라 "진단 → 처방 선택"을 중심에 둔다.**

| 방법 중심으로 쓰면 | 진단 중심으로 쓰면 |
|---|---|
| P는 혼합 정밀도, M은 SmoothQuant/AWQ 계열이라 "기존 기법 조합"으로 읽힌다 | P·M이 기존 기법이라는 점을 인정하고, "언제·어디에 쓰는지를 정하는 절차"가 기여가 된다 |
| G가 YOLO-World에만 적용된다는 점이 약점 | G는 분석이 찾은 메커니즘(게이트 분기의 공유 scale 오염)에 대한 처방. 게이트가 없으면 진단이 다른 처방을 고른다 |
| 모델마다 G/P/M 중 못 쓰는 게 있다는 점이 약점 | "모델마다 진단이 알맞은 처방을 고른다"는 근거가 된다(R3) |
| OWLv2에서 P가 안 듣는 것이 실패 | 분석이 예측한 결과 |

**제목 후보:** *Where Low-Bit Quantization Breaks Open-Vocabulary Detectors: Diagnosis-Guided Post-Training Quantization*

**기여 문장(Introduction 끝):**
1. 판정 충실도(LVIS flip, lost)로 본 저비트 OVOD의 숨은 실패(R1).
2. 누수 없는 층 단위 진단과, 손상 구조가 아키텍처를 따른다는 분석(R2, 메커니즘).
3. 진단 기반 처방: 비트 비용 0의 게이트 교환과, 진단·사전 검사로 켜는 보호·이전(R3~R6).
4. 엄격한 프로토콜과 6개 검출기(CNN 2계열 + ViT)에서의 결정적·재현 가능한 평가(R7, R8).

## 5. 쓰는 방식 — 이렇게 쓰고, 이렇게 쓰지 않는다

| 이렇게 쓴다 | 이렇게 쓰지 않는다 |
|---|---|
| "W4에서 6개 모델 모두 유의하게 개선" | "모든 비트에서 개선" (W8A8은 m·YOLOE에서 AP 차이 없음, flip 감소가 주된 효과) |
| "진단이 잡아내는 손상량과 P의 효과가 일관된 경향을 보인다" | "손상량이 효과를 결정한다"(인과) |
| "P와 M은 기존 기법 계열이며, 기여는 적용 위치와 시점의 선택" | "새로운 혼합 정밀도 기준" (P는 HAWQ식과 비슷, 차이 비유의) |
| "이전 규칙(M/AWQ/SmoothQuant)은 바꿔 써도 결론이 같다" | "M이 SmoothQuant/AWQ보다 항상 낫다" (s에서는 AWQ가 flip을 조금 더 줄임) |
| "BRECQ가 무너지는 W4A5에서 FP의 74~89%까지 회복" | "W4A5가 실용 수준" |
| "W4A8에서는 PM이 GPM보다 약간 높다(s, v2)"를 표에 그대로 | 비트마다 구성을 바꿔 가장 좋은 값만 싣기 |
| "per-tensor A4는 열지 못했다" | W4A4 언급 회피 |
| OWLv2는 "진단과 처방 선택이 ViT에서도 맞게 작동한다" | OWLv2 절대 성능 경쟁 (W4A8은 FP의 66%) |

## 6. 리뷰어 예상 질문과 지금 가진 답

| 질문 | 답 | 보강 필요 |
|---|---|---|
| P·M은 기존 기법 아닌가 | 맞다. 기여는 "언제·어디에"를 판정 기준의 누수 없는 진단이 정한다는 것(표 A, 그림 2). 무작위 보호 +0.21 vs P +1.05 | – |
| 휴리스틱 아닌가, 다른 데이터에도 되는가 | 모든 선택이 평가 데이터를 보지 않는 고정 규칙이고 6개 구조에 같은 규칙 | **다른 평가 데이터(ODinW/Objects365), 다른 calibration 데이터 미검증** |
| SOTA와 비교는 | 같은 조건에서 기존 PTQ 6종보다 우세 | **문헌 방법 1개 재구현(PD-Quant/Reg-PTQ), QATMA 조건 비교 없음** |
| G는 YOLO-World 전용 아닌가 | YOLO-World 계열은 널리 쓰이는 실시간 OVOD. 게이트가 없으면 진단이 다른 처방을 고른다 | – |
| attention·DFL을 FP로 둔 것 아닌가 | attention·region–텍스트 내적 8bit에서도 유지. DFL은 고정 디코딩 연산 | – |
| M 검사가 틀리는 경우는 | v2 W8A8을 놓친다. 한계로 명시 | – |
| 실기기에서 빠른가 | 연산 형태가 기준선과 같고 크기 +0.3% | **실측 없음** |

## 7. 제출 전까지 할 일 (우선순위)

1. **다른 평가 데이터** — 만든 모델(BRECQ / ours)을 ODinW-13 또는 Objects365 val로 평가. 일반화 질문의 가장 큰 구멍.
2. **문헌 방법 1개 재구현** — PD-Quant(저장소에 일부 구현이 남아 있음) 또는 Reg-PTQ를 같은 프로토콜로.
3. **그림 1, 3, 4** — 데이터는 모두 있음.
4. **다른 calibration 데이터** — YOLO-World-S W4A8·W4A5에서 진단 목록과 성능이 유지되는지.
5. **본문 초안** — 4절(분석)과 6절(실험)부터. 수치는 이 문서의 표를 그대로 쓴다.
6. (여유가 있으면) QATMA 조건(YOLO-World-L, 첫·마지막 FP), OWLv2 W4A5 붕괴 확인(naive/BRECQ 1 seed), 실기기 지연.
