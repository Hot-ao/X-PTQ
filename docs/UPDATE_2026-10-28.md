# 변경 사항 정리 (2026-10-27 ~ 28)

**대상:** 이 저장소로 같이 실험하는 팀원. 이틀 동안 바뀐 코드, 새로 생긴 데이터·모델, 새 결과, 진행 중인 실험을 한곳에 모았다. 논의 내용과 앞으로의 실험 계획은 [`MEETING_2026-10-28.md`](MEETING_2026-10-28.md), 수치 표는 [`RESULTS.md`](RESULTS.md) §4c·§4d에 있다.

## 1. 요약

- **일반화:** COCO/LVIS 밖 도메인인 ODinW-13(13개 데이터셋)에서 평가했다. W4A5에서는 세 모델 모두 LVIS보다 큰 폭으로 개선된다(BRECQ 대비 +3.3 / +7.9 / +9.7).
- **W4A4:** 9월에 한계로 적었던 W4A4가 GPM으로 동작한다. BRECQ는 붕괴(LVIS 0.5)하고, GPM은 YOLO-World-S에서 LVIS 18.2~18.7(FP의 70~72%)이다. A4를 살리는 요소는 M이다.
- **자동 처방:** M 사전 검사의 결정을 모델·비트별로 저장해, 모든 모델에 같은 명령(`brecq+GPMA`)을 쓰면 G·P·M이 자동으로 정해진다.
- **기준선:** PD-Quant(CVPR'23)를 구현했다. 파일럿을 실행 중이다.
- **인프라:** 양자화 모델을 저장하고 다시 불러올 수 있다. 이제 평가를 바꿀 때 다시 빌드할 필요가 없다.

**PD-Quant 구현 메모** (자세한 내용은 `quant/pdquant.py` 머리말)
- 공식 코드(github.com/hustvl/PD-Quant, e12038e)를 따랐다. 공식 구현이 QDrop 위에 만들어져 있어서, 저희 `qdrop`과 같은 설정(재구성 단위, 2000 iter, batch 1, drop 0.5, LSQ)에 PD 손실과 DC만 더했다.
- 검출기에 옮기며 정한 것:
  - 예측: head 원시 출력의 클래스 분포와 박스(DFL) 분포를 둘 다 쓴다.
  - 블록 뒤쪽 네트워크: FP 모델에 블록 출력을 바꿔 끼워 통과시킨다.
  - BN 통계: 양자화 전에 BN이 conv에 합쳐지므로, 합치기 전 모델에서 모은다.
  - KL: 공식 `batchmean`과 같이 anchor에 대해 합한다. 그래서 PD 손실이 재구성 손실보다 훨씬 크다.
- 확인한 것:
  - QDrop 경로는 수정 전과 같다.
  - PD gradient가 대상 파라미터에만 간다.
  - FP 출력을 그대로 끼우면 PD 손실이 0에 가깝다.
  - DC는 BN 통계 오차를 15% 줄인다(입력 변화 7.9%).
  - 짧은 설정에서 따로 둔 이미지의 FP 대비 예측 KL이 QDrop보다 4% 낮다.

## 4. 새 사용법

```bash
source scripts/protocol.sh

# ODinW만 평가(LVIS 생략, COCO AP는 같은 모델인지 확인용)하고 모델 저장
.venv/bin/python run_comparison.py $PROTOCOL --model yoloe-v8s-seg.pt --w-bits 4 --a-bits 5 \
    --conditions brecq,brecq+GPM --seed 0 --odinw-only --save-model /data/taeho/cvpr2027_qmodels --device 5

# 저장된 모델로 빌드 없이 다시 평가(같은 인자로 실행해야 파일 이름이 맞는다)
.venv/bin/python run_comparison.py $PROTOCOL --model yoloe-v8s-seg.pt --w-bits 4 --a-bits 5 \
    --conditions brecq,brecq+GPM --seed 0 --odinw-only --load-model /data/taeho/cvpr2027_qmodels --device 5

# 규칙대로 M을 정하는 우리 방법(처음이면 검사 후 configs/mcheck_cache/에 저장, 다음부터는 저장된 결정 사용)
.venv/bin/python run_comparison.py $PROTOCOL --model yolov8m-world.pt --w-bits 4 --a-bits 4 \
    --conditions brecq,brecq+GPMA --seed 0 --device 5

# PD-Quant와 그 위의 GPM
.venv/bin/python run_comparison.py $PROTOCOL --model yolov8s-world.pt --w-bits 4 --a-bits 8 \
    --conditions pdquant,pdquant+GPM --seed 0 --device 5
```
