  - 10-03 14:25 이전에 시작한 실행의 로그는 conv weight만 센 값이다(s는 0.44 MiB 작음). 리더보드의 크기 열은 10-09부터 이 차이를 더해 맞춘다(`make_leaderboard.py`의 `fix_size`). v2는 실행 중 입력을 받는 Linear가 없어 차이가 없고, m은 0.48 MiB가 더해진다(BRECQ·GPM 14.10 MiB).
  - 텍스트 상수(guide projection 결과, contrastive 텍스트)는 어휘마다 달라지는 값이라 크기에서 뺐다. LVIS 기준 약 1 MB다.
